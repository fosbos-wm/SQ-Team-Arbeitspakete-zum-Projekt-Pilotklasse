# SQ-Team-Projekt 26/27: Pilotklasse

GitHub-Pages-Web-App für 12 Arbeitspakete des SQ-Teams.

**Enthalten:** `index.html`, `styles.css`, `app.js`, `logo.jpg`, `README.md`

## Layout
- Desktop: 6 Karten nebeneinander
- kleinerer PC/Tablet: 4 bzw. 2 Spalten
- Smartphone: genau 1 Spalte
- Padlet-ähnliche Kartenansicht

## Ampel
🟢 Auf Kurs · 🟡 Klärungsbedarf · 🔴 Handlungsbedarf

## GitHub Pages
Dateien direkt ins Repository-Hauptverzeichnis hochladen → Settings → Pages → Deploy from a branch → `main` + `/ (root)` → Save.

## Hinweis
Die App speichert aktuell lokal im Browser. Für gemeinsame Bearbeitung durch alle Lehrkräfte wird anschließend eine gemeinsame Datenbank benötigt.
